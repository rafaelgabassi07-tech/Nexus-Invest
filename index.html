Criptografia Local Zero-Knowledge

Seus investimentos não pertencem a ninguém a não ser você.

A maioria dos aplicativos gerencia seu portfólio salvando dados em texto aberto no servidor. Se o servidor for hackeado, seus saldos são expostos. No VALORAE, isso é impossível.

🔑 O funcionamento é extremamente prático:

  • Cifragem na Origem: Os dados são empacotados em JSON, encriptados de forma assimétrica/simétrica com AES-256-GCM no chip criptográfico local do Android.
  • Tráfego Oculto: O tráfego para a ponte Vercel envia apenas o ciphertext criptografado sem conter sua senha ou frase-semente.
  • Armazenamento Cego: O banco do Supabase apenas retém o hash cifrado. Somente você pode restaurar e ler os ativos digitando sua senha privada no celular.
Guia Prático do Servidor

Como configurar o Vercel & Supabase de ponta-a-ponta

Com os arquivos já publicados no seu repositório sincronizado com o GitHub, siga o roteiro de 3 passos abaixo para deixar o sistema 100% online.

Criar a Tabela de Backups

Execute este script no painel SQL Editor do seu projeto Supabase.

-- 1. Criar a Tabela de Backups Sincronizados
CREATE TABLE IF NOT EXISTS valorae_sync_backups (
    user_id TEXT PRIMARY KEY,
    payload TEXT NOT NULL,
    encrypted BOOLEAN DEFAULT FALSE,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

-- 2. Desabilitar RLS (Recomendado para uso com chave anônima oculta no Vercel)
ALTER TABLE valorae_sync_backups DISABLE ROW LEVEL SECURITY;
Por que desabilitar o RLS é seguro aqui? Os dados do payload são criptografados pelo app diretamente no seu celular (com AES-256 baseado na frase-semente que apenas você sabe). O banco apenas armazena bytes ilegíveis e sem dados pessoais visíveis nos logs de rede, evitando qualquer possibilidade de leitura externa da sua carteira de investimentos.

Configurar as Variáveis de Ambiente no Vercel

Como as chaves serão acessadas apenas no lado do servidor, elas nunca vazarão no aplicativo compilado.

Variável 1 (Nome) SUPABASE_URL

Insira a URL de conexão do seu Supabase. Encontre em Project Settings > API no Supabase.

ex: https://mynbpxg...supabase.co
Variável 2 (Nome) SUPABASE_ANON_KEY

Insira a chave JWT anônima do projeto (marcada como anon / public).

ex: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Tutorial passo-a-passo:

  1. Abra seu painel no Vercel Dashboard e acesse seu projeto.
  2. Clique na aba Settings no topo e depois vá em Environment Variables no menu lateral esquerdo.
  3. Adicione a variável SUPABASE_URL e cole a respectiva URL obtida nas configurações do Supabase.
  4. Adicione a variável SUPABASE_ANON_KEY e cole a chave anônima.
  5. Clique em Save. Dica: Faça um novo "Deploy" para as variáveis entrarem em vigor em alguns segundos!

Configurar a URL do Vercel no Aplicativo Android

Conecte o APK do Android diretamente ao seu servidor Vercel.

CHAVE DE INJEÇÃO (SEGREDO NO STUDIO)
VERCEL_BACKEND_URL Segredos

No painel lateral do seu chat no AI Studio, acesse as configurações de Secrets (Segredos) e adicione o segredo com o nome VERCEL_BACKEND_URL contendo a URL gerada pelo Vercel.

Valor da Secret (Exemplo):
https://meu-projeto-valorae.vercel.app
Atenção! Limpe suas variáveis antigas: Certifique-se de remover ou deixar em branco as variáveis antigas SUPABASE_URL e SUPABASE_ANON_KEY no painel de Segredos do AI Studio. Quando estas variáveis do Supabase estão apagadas no app, o Android detecta automaticamente a ausência delas e passa a enviar as requisições de backup e restauração de forma exclusiva e ultra-segura pela sua rota da Vercel!

Atualizações Automáticas Over-The-Air (OTA)

Este site não serve apenas para hospedar a interface de introdução e o servidor proxy das chaves. Ele também serve como o núcleo de distribuição de atualizações automáticas via internet para o aplicativo Android!

Sempre que você atualizar o app, tudo que precisa fazer é:

  • 1 Gerar o arquivo app-release.apk de uma nova versão estável (por exemplo, 1.0.6 com versionCode 7).
  • 2 Criar uma nova Release pública no seu GitHub e colocar o link direto do APK no campo downloadUrl do arquivo update.json na sua árvore de código.
  • 3 Atualizar as informações de versionCode, versionName e changelog do arquivo update.json e subir para o GitHub.

🚀 A Vercel fará a re-publicação estática em segundos, e o aplicativo instalado no celular do seu usuário identificará o novo arquivo de metadados na inicialização do app, avisando ao seu usuário e baixando e instalando a atualização de forma totalmente autônoma e segura!

Estrutura do arquivo update.json

{
  "latestVersionCode": 6,
  "versionName": "1.0.5",
  "downloadUrl": "https://github.com/...",
  "releaseDate": "2026-05-22",
  "changelog": [
    "✓ Desempenho de carregamento acelerado do portfólio",
    "✓ Novo sistema de backup seguro via ponte Vercel"
  ]
}

Você pode ler e editar este arquivo chamado update.json localizado diretamente na pasta raiz do seu repositório.
