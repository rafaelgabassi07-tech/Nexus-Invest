Guia de Implantação

Instalar e Configurar o Backend Serverless

Sincronize sua carteira com a nuvem utilizando a ponte automática da Vercel para Supabase.

Passo 1: Criar a Tabela Sincronizada

CREATE TABLE IF NOT EXISTS valorae_sync_backups (
    user_id TEXT PRIMARY KEY,
    payload TEXT NOT NULL,
    encrypted BOOLEAN DEFAULT FALSE,
    updated_at TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);
ALTER TABLE valorae_sync_backups DISABLE ROW LEVEL SECURITY;

Cole este script no SQL Editor do painel Supabase para abrir suporte para salvamento de backups.

Passo 2: Configurar Chaves de API na Vercel

Adicione as seguintes variáveis de ambiente no dashboard do seu projeto Vercel para ocultar as senhas finais e prevenir engenharia reversa no APK:

SUPABASE_URL

URL obtida em Project Settings > API do Supabase.

SUPABASE_ANON_KEY

Chave pública JWT do projeto (anon / public).

Passo 3: Chave Secundária no AI Studio

No menu de Secrets do painel lateral do AI Studio, crie a chave do ambiente para integrar o APK:

Chave: VERCEL_BACKEND_URL

Valor: https://seu-projeto-valorae.vercel.app

Dica: Limpe quaisquer variáveis SUPABASE_URL ou SUPABASE_ANON_KEY do AI Studio, para que o aplicativo force o tráfego exclusivamente através da ponte segura da Vercel.

Monitor Operacional da Ponte

Insira o link do seu backend Vercel para disparar um handshake e testar de forma síncrona se a comunicação com o Supabase está online.
